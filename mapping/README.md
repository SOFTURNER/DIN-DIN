# Mapping + Event finder

Self-contained DIN feature module. Import from the folder root:

```ts
import MappingPage from '../mapping'
// or
import { MappingPage } from '../mapping'
```

Styles and earth textures travel with the import — no extra CSS step.

Mount in a full-height parent:

```tsx
<div className="h-screen">
  <MappingPage />
</div>
```
